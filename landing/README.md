# VibeCheck Landing Page

This folder contains a standalone landing page styled to match the main frontend app.

## Files

- `index.html`: landing page markup
- `styles.css`: visual styles aligned with the app theme (`frontend/src/index.css` and `frontend/src/App.css`)

## Run locally

Open `landing/index.html` directly in a browser, or serve the repository with any static server.

The call-to-action buttons point to `https://my.vibeaura.app`.
